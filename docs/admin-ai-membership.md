# AI 로그인 제한 / 관리자 콘솔

- `/ai/`는 서버에서 회원 세션을 확인하며 익명 사용자는 로그인/회원가입 안내를 본다.
- `/api/ai/questions`도 매 요청마다 회원 API로 세션을 재검증한다. 페이지 숨김만으로 제한하지 않는다.
- 로그인·회원가입의 `next`는 허용된 내부 경로만 사용한다. AI 페이지에서 인증하면 AI 페이지로 복귀한다.
- 로그인 도중 세션이 만료되면 재로그인 안내를 표시한다.
- 관리자 콘솔은 운영 개요 / AI 이용 현황 / 회원 조회 / 데이터 품질 탭을 제공한다. 현재 관리자 권한 확인 이후에만 조회하며 API도 별도로 검사한다.
- 서비스 상태는 조회/회원/투표 API의 현재 health 응답이다. AI 모델의 준비 상태로 해석하지 않는다.
- AI 기록에는 질문을 저장하지 않는다. 적용 이전 사용량은 소급 생성하지 않는다.
- 모바일 390px에서 관리자 검색/카드/탭을 확인했다. 시각 검증은 별도의 로컬 합성 데이터로 수행했으며 운영자 사칭이나 운영 계정 생성은 하지 않았다.

Backend의 `docs/admin-ai-membership.md`에 기재한 명시적 DB 마이그레이션과 API 배포가 선행되어야 한다. 기존 회원·AI 환경변수를 재사용하며 공개 환경변수에 서비스 토큰을 넣지 않는다.
